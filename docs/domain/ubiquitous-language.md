# Ubiquitous Language

| Term | Meaning | Notes |
|---|---|---|
| Team | The central organizing unit. All schedules, rosters, announcements, and results belong to a team. | Owned by a Coach who created it |
| Member | A registered User who belongs to a Team under a specific Role. | One User may be a Member of multiple Teams |
| Role | The function a Member performs on a Team. One of: `COACH`, `ASSISTANT_COACH`, `TEAM_MANAGER`, `SCOREKEEPER`, `PLAYER`, `PARENT`. | Determines write permissions; see [Role Assignment](../bounded-contexts/team.md) |
| Coach | A Member with the `COACH` role. Has full write access to all team features. | Automatically assigned to the Team creator |
| Player | A Member with the `PLAYER` role. Has read and RSVP access. | |
| Parent | A Member with the `PARENT` role, linked to one or more Players on the Roster. Can RSVP on behalf of linked Players. | |
| Roster | The list of Player profiles managed by the coaching staff for a Team. | Distinct from Membership: a RosterEntry can exist before the Player has a User account |
| RosterEntry | A single Player record on a Roster, containing name, jersey number, and position. | At most one entry per Player per Team |
| Season | A named date range that scopes Events, Results, and the win/loss record for a Team. Only one Season may be active at a time. | Archived Seasons are read-only |
| Active Season | The current, non-archived Season. New Events and Results are scoped to it. | |
| Archived Season | A past Season that is read-only; its schedule and record remain accessible. | |
| Event | A scheduled team activity with a title, type, date/time, and location. Types: `GAME`, `PRACTICE`, `MEETING`, `OTHER`. | Belongs to a Season |
| EventStatus | Lifecycle state of an Event: `SCHEDULED` (default) or `CANCELLED`. | See BDR-015 |
| RecurringEventSeries | A template that generates individual Event instances on a repeating schedule (e.g., weekly). | Each instance is an independent Event |
| RSVP | A Member's declared intent to attend an Event: `GOING`, `NOT_GOING`, or `MAYBE`. Only the latest response is retained. | Parents may RSVP on behalf of linked Players |
| Attendance | The factual post-event record of which Players were `PRESENT` or `ABSENT`. Only recordable for past Events. | |
| GameResult | The score, derived outcome (win/loss/tie), and optional notes for a completed Game-type Event. | |
| Season Record | Aggregate win/loss/tie counts for a Season, recomputed from all GameResults in that Season. | Resets to 0–0–0 on new Season creation |
| Announcement | A coach-authored message broadcast to a targeted audience: `PLAYERS`, `PARENTS`, or `ALL`. | May be marked urgent |
| Notification | An in-app alert generated by the system when a noteworthy domain event occurs (schedule change, new announcement, game result, event reminder). | Has `READ` / `UNREAD` state |
| Invite | A time-limited, role-scoped token that grants a registered User membership in a Team. | May be revoked before acceptance |
| Version | An optimistic-concurrency counter on Event. Required on PATCH and cancellation requests; mismatch returns HTTP 409. | |
| Overlap Warning | A non-blocking alert in the API response when a newly created or edited Event's time window overlaps another Event on the same team. | |
| Cancellation Reason | Optional free-text field stored on a CANCELLED Event, surfaced to all Members. | |

## Deprecated or Ambiguous Terms

| Term | Problem | Preferred Term |
|---|---|---|
| User | Too generic — conflates account identity with team participation | Member (for team context), User (for Identity context only) |
| Admin | Used informally; no formal `ADMIN` role exists | Coach |
| Staff | Informal catch-all for non-player roles | Coaching Staff (COACH, ASSISTANT_COACH, TEAM_MANAGER, SCOREKEEPER) |
